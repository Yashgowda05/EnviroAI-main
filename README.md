# 🌍 EnviroAI

> AI Powered Environmental Mapping & Smart Travel Assistant

## 📖 Overview

EnviroAI is a smart travel planning application that helps users plan safer and more efficient trips using Artificial Intelligence, Google Maps Platform, weather forecasts, air quality monitoring, and route optimization.

---

## ✨ Current Features

- 🔐 Google Authentication (Firebase)
- 🗺️ Google Maps Integration
- 📍 Current Location Detection
- 🛣️ Route Planning
- 🌤️ Current Weather Information
- 🌿 Air Quality Monitoring
- ⚡ Express.js Backend
- 🍃 MongoDB Atlas Database

---
